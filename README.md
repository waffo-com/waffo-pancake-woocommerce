# Waffo Pancake — Platform Plugins

Official plugins that connect e-commerce / CMS platforms to
[Waffo Pancake](https://pancake.waffo.ai), the Merchant of Record for software
and digital products. Each plugin lives in its own directory and ships
independently.

| Plugin | Platform | Status | Directory |
|---|---|---|---|
| Waffo Pancake for WooCommerce | WordPress + WooCommerce | 🚧 In development | [`woocommerce/`](./woocommerce) |

Want a plugin for another platform (Shopify, Ghost, Webflow, …)? Open an issue
or a pull request — see [CONTRIBUTING.md](./CONTRIBUTING.md).
